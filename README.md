# Advanced Machine Learning

This repository contains coursework and projects completed as part of my M.S. in Business Analytics at Kent State University.

## Topics Covered

- Neural networks and deep learning
- Model generalization
- Underfitting and overfitting
- Regularization and dropout
- Model performance evaluation
- Hyperparameter tuning
- Predictive modeling

## Tools and Technologies

- R
- Python
- Jupyter Notebook
- Machine Learning
- Neural Networks
- Statistical Analysis
- Data Visualization

## Repository Purpose

The projects in this repository demonstrate the application of advanced machine learning techniques to build, evaluate, and improve predictive models. The work focuses on model performance, generalization, and the practical application of machine learning methods to data analysis problems.
